# دعوت به قرار — HTML اصلی + Node.js

طراحی از فایل HTML ارسالی کاربر گرفته شده است. CSS اصلی بدون تغییر نگه داشته شده؛ رابط کاربری، استایل‌ها، جاوااسکریپت و فونت وزیرمتن همگی داخل **یک فایل `index.html`** قرار دارند. فایل HTML جداگانه‌ای برای مراحل دیگر لازم نیست. فونت داخل HTML بسته‌بندی شده و درخواست خارجی ندارد.

## اجرا روی ویندوز، مک و لینوکس

فقط Node.js نسخهٔ 20.19 یا جدیدتر لازم است. برای اجرای سایت نیازی به نصب پکیج یا build نیست:

```sh
node server.js --port 5173
```

سپس `http://localhost:5173` را در مرورگر باز کنید. یا:

```sh
npm start -- --port 5173
```

اجرای توسعه با انتخاب خودکار پورت آزاد در صورت اشغال پورت:

```sh
npm run dev -- --port 5173
```

آدرس واقعی مقابل `Local` چاپ می‌شود. ترتیب تعیین پورت: `--port`، سپس `PORT`، سپس `API_PORT` و پیش‌فرض `5173`. فقط یک پردازهٔ Node هم HTML و هم API را ارائه می‌کند؛ Vite، پروکسی توسعه و پورت مجزای API وجود ندارند.

## استفاده

- در صفحهٔ اصلی اسم مخاطب را بنویسید و «ساخت لینک» را بزنید.
- لینک دعوت را برای مخاطب بفرستید؛ «پیش‌نمایش» همان دعوت را باز می‌کند.
- لینک خصوصیِ نتیجه را برای خودتان نگه دارید. این لینک نباید برای مهمان فرستاده شود.
- پاسخ‌ها در مرورگرهای جدا هم به سرور می‌رسند؛ دعوت‌های ساخته‌شده در همان مرورگر در قسمت نتیجه‌ها نیز دیده می‌شوند.
- انتخاب روز از هفت روز آینده، تاریخ شمسی، انتخاب ساعت، غذا، تعداد «نه»، قلبِ لمس و جشن نورانی همان رفتار فایل مرجع را دارند. با فعال‌بودن کاهش حرکت سیستم، افکت‌های متحرک اجرا نمی‌شوند.

`index.html` را برای نتیجه‌های مشترک از طریق سرور باز کنید؛ بازکردن مستقیم آن با `file://` به API دسترسی ندارد. برای نمایش صرفِ ظاهر، مسیر `/?demo=1` روی سرور قابل استفاده است.

## داده‌ها و انتشار بعدی

پاسخ‌ها در `.data/invitations.json` ذخیره می‌شوند. با `DATA_DIR` می‌توانید مسیر ذخیره را عوض کنید. این پوشه باید روی هاست ماندگار باشد؛ اطلاعات دعوت‌ها و کلیدهای مدیریت را منتشر نکنید. لینک خصوصی جایگزین ورود به حساب است؛ هر کس آن را داشته باشد نتیجهٔ همان دعوت را می‌بیند.

این نسخه برای یک پردازهٔ Node است. برای لینک عمومی، HTTPS و دامنه/آدرس هاست لازم است؛ تغییر دامنه لینک‌های قبلی را خودکار منتقل نمی‌کند. مسیر `/healthz` برای بررسی سلامت سرور است. داکرایز کردن مطابق درخواست کاربر به بعد از تأیید این نسخه موکول شده و هنوز Dockerfile اضافه نشده است.

## تست

فقط برای تست، وابستگی‌های توسعه را نصب کنید:

```sh
npm ci
npm test
npm run test:startup
```

تست مرورگر از `/usr/bin/chromium` استفاده می‌کند؛ برای دستگاه دیگر مسیر مرورگر را در `playwright.config.js` تنظیم کنید. تست‌ها یکسان‌بودن CSS و تصویر کارت دعوت با فایل اصلی، ساخت دعوت، دریافت پاسخ از مرورگر دیگر، لینک خصوصی، لمس، کاهش حرکت، ذخیره بعد از راه‌اندازی مجدد و پورت اشغال را بررسی می‌کنند. فایل `tests/fixtures/reference.html` فقط نمونهٔ اصلی برای مقایسه است و سرور آن را ارائه نمی‌کند.
