# یه قرار کوچولو ♡

دعوت‌نامهٔ فارسی و واکنش‌گرا، الهام‌گرفته از ویدیوی مرجع: قبول دعوت، انتخاب تاریخ و ساعت، انتخاب غذا و کپی خلاصهٔ قرار.

## اجرا

Node.js 20.19+ یا 22.12+ نیاز است.

```sh
npm ci --cache /tmp/invite-npm-cache
npm run dev -- --port 5173
```

```sh
npm run build
npx playwright test
```

آزمون‌ها از Chromium نصب‌شده در `/usr/bin/chromium` استفاده می‌کنند؛ برای محیط‌های دیگر مسیر مرورگر را در `playwright.config.js` تنظیم کنید.

فونت وزیرمتن همراه پروژه بسته‌بندی می‌شود و هنگام استفاده نیازی به سرویس فونت خارجی ندارد. نسخهٔ فعلی بک‌اند دارد و پاسخ‌ها را روی سرور ذخیره می‌کند. برای انتشار، دستورهای بخش دعوت شخصی را دنبال کنید. تغییر متن دعوت در `src.js` و ظاهر در `style.css` انجام می‌شود.

## دعوت شخصی و نتایج

صفحهٔ اصلی فرم ساخت دعوت است. نام مخاطب، نام فرستنده و پیام اختیاری را وارد کنید؛ دو لینک ساخته می‌شود: لینک مهمان و لینک خصوصی مدیریت. کلید مدیریت در fragment لینک است و برای خواندن نتیجه به API فرستاده می‌شود. لینک مدیریت را محرمانه نگه دارید؛ ورود با حساب کاربری وجود ندارد. دعوت‌های ساخته‌شده در همان مرورگر نیز در «دعوت‌های من» فهرست می‌شوند.

با هر کلیک روی «نه»، «آره» تا ۸ بار بزرگ‌تر می‌شود؛ «نه» همواره قابل استفاده است. پاسخ «نه» ثبت می‌شود و با تأیید نهایی «آره»، نتیجه به‌روزرسانی می‌شود. اگر مخاطب فرم را کامل نکند، تأیید نهایی ثبت نمی‌شود. دکمهٔ بررسی دوباره، آخرین پاسخ را از سرور می‌خواند.

اجرای توسعه: `npm run dev -- --port 5173` هم Vite و هم API را اجرا می‌کند. اجرای عمومی: ابتدا `npm run build` و سپس `npm start`. پورت پیش‌فرض سرور تولید 3001 است (قابل تغییر با `API_PORT`). سرور هم فایل‌های فرانت‌اند و هم API را ارائه می‌کند. برای ارسال لینک به دستگاه دیگر به میزبانی Node.js با HTTPS و فضای ذخیره‌سازی دائمی نیاز دارید. مسیر `DATA_DIR` را روی فضای دائمی قرار دهید؛ پیش‌فرض `.data/` است. داده‌ها در فایل JSON با نوشتن اتمی ذخیره می‌شوند؛ این پیاده‌سازی برای یک پردازهٔ Node است. چند replica یا فایل‌سیستم موقت مناسب نیست. فایل HTML مستقل قدیمی شامل قابلیت‌های سرور جدید نیست.

برای انتشار از `npm start` استفاده کنید؛ میزبانی استاتیک `dist` به‌تنهایی کافی نیست.

اگر پورت API در توسعه اشغال باشد، `npm run dev` خودکار پورت آزاد انتخاب می‌کند و Vite را به همان پورت وصل می‌کند. پیام `API ready on port …` پورت انتخاب‌شده را نشان می‌دهد. آدرس مرورگر همان آدرس نمایش‌داده‌شده توسط Vite است. در تولید، اشغال پورت همچنان خطاست تا تنظیمات میزبان تغییر نکند.
